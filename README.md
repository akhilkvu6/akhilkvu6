<h2 align="center">04 · FEATURED ENGINEERING PROJECT</h2>

<h1 align="center">🔐 CipherVault</h1>

<p align="center">
  <strong>PRIVATE · SELF-HOSTED · ENCRYPTED CLOUD STORAGE</strong>
</p>

<p align="center">
  <a href="https://github.com/akhilkvu6/CipherVault">
    <img src="https://img.shields.io/badge/VIEW%20PROJECT-161B22?style=for-the-badge&amp;logo=github&amp;logoColor=white" alt="View CipherVault"/>
  </a>
  <img src="https://img.shields.io/badge/ANDROID-JAVA-3DDC84?style=flat-square&amp;logo=android&amp;logoColor=white" alt="Android Java"/>
  <img src="https://img.shields.io/badge/SPRING%20BOOT-6DB33F?style=flat-square&amp;logo=springboot&amp;logoColor=white" alt="Spring Boot"/>
  <img src="https://img.shields.io/badge/MYSQL-4479A1?style=flat-square&amp;logo=mysql&amp;logoColor=white" alt="MySQL"/>
</p>

CipherVault is a private, self-hosted cloud-storage system designed to protect and manage personal files through authenticated encryption, secure transfers, duplicate detection and metadata indexing.

It combines a native Android application, a Spring Boot backend, a MySQL database and an optional desktop server-management utility.

### System Architecture

```text
                 ANDROID CLIENT
                 Java 21 / Material 3
                         |
                         |
                   Retrofit / OkHttp
                         |
                         v
                  SPRING BOOT API
                         |
          +--------------+--------------+
          |              |              |
          v              v              v
      SECURITY       ENCRYPTION      STORAGE
       JWT           AES-256-GCM     FILE ENGINE
          |              |              |
          +--------------+--------------+
                         |
                         v
                    MYSQL 8.0+

             OPTIONAL DESKTOP UTILITY
                    Python / PySide6
```

### Engineering Highlights

  <tr>
    <td width="50%" valign="top">

        <li>Stateless JWT authentication</li>
