<h2 align="center">04 · FEATURED PROJECT</h2>

<h3>🔐 CipherVault</h3>

<p>
  <a href="https://github.com/akhilkvu6/CipherVault">
    <img src="https://img.shields.io/badge/VIEW%20PROJECT-161B22?style=for-the-badge&logo=github&logoColor=white" alt="View CipherVault"/>
  </a>
  <img src="https://img.shields.io/badge/ANDROID-JAVA-3DDC84?style=flat-square&logo=android&logoColor=white" alt="Android Java"/>
  <img src="https://img.shields.io/badge/SPRING%20BOOT-6DB33F?style=flat-square&logo=springboot&logoColor=white" alt="Spring Boot"/>
  <img src="https://img.shields.io/badge/MYSQL-4479A1?style=flat-square&logo=mysql&logoColor=white" alt="MySQL"/>
</p>

A private, self-hosted encrypted cloud-storage system combining a native Android application, a Spring Boot backend and an optional desktop server-management utility.

**Architecture**

```text
Android Client
(Java 21 / Material 3)
        |
        | Retrofit / REST API
        v
Spring Boot Backend
        |
        +---- Authentication & Security
        |
        +---- AES-256-GCM Encryption
        |
        +---- File Storage & Metadata
        |
        v
     MySQL Database

Optional Python / PySide6
Desktop Server Manager
```

**Engineering highlights**

- AES-256-GCM authenticated encryption
- PBKDF2-based per-user key derivation
- SHA-256 duplicate-file detection
- Metadata extraction and indexing
- Chunked file transfers with progress reporting
- Android biometric application lock
- Spring Security and stateless JWT authentication
